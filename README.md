# Nagisaland 手机版（安卓）v0.6.3

手机上的 galgame 一站式 App，底部四个页面：

- **游戏库**：RPG Maker MV / MZ、TyranoScript 直接在 App 里玩（屏幕按键 + 修改器，每个游戏存档分开）；
  打包在 exe / package.nw / app.asar 里的网页游戏，点「解包」一次后也能直接玩；
  游戏文件夹里带着电脑版存档（save/）的，第一次打开自动导入；MV/MZ 在手机上存档时也会同步写一份到 save/（电脑版能直接读，卸载 App 不丢）；
  记录每个游戏的游玩时长；没有封面的游戏可以一键从小站补全封面；
  其它 20 多种引擎自动识别，并和模拟器打通：PSP 游戏装了 PPSSPP 点一下直接开始；era / ONScripter / EasyRPG 游戏一键放进模拟器自己的游戏目录，打开模拟器游戏就在列表里；其它模拟器调起 App 并复制好游戏路径；
  电脑上「导出到安卓」打包好、已经装在手机上的游戏 App，右上角 ＋ 里点「添加」就能放进游戏库，从这里启动会记游玩时长；
  游戏文件夹名是网盘编号（如 4383）时，游戏库自动用里面有意义的文件夹名显示；详情里「整理文件夹」可以一键删广告、去多余层、按小站 / 游戏名改名；
  每个游戏都能改名、移出游戏库（可恢复）、删除游戏文件（两次确认）或卸载 App；游戏库可以按名称 / 最近玩 / 游玩时长 / 加入时间排序。
- **小站**：和电脑版一样登录自己的小站 → 搜索 → 看详情 → 获取下载链接；点「打开」先复制提取码再跳网盘 App，解压密码单独列出一键复制。
- **解压**：内置 7-Zip（7z / rar / zip、分卷、有密码的都行），和电脑版一样一键到底：自动改回伪装后缀、认分卷 → 按小站资源依次试解压密码（也可以自己填）→ 压缩包里还是压缩包就接着解（最多 6 层）→ 删广告文件 → 去掉多余的文件夹层 → 用小站的名字命名、下载封面 → 放进游戏库；可选解压成功后删除压缩包。
  「下载目录…」里可以直接浏览手机文件夹来添加；用别的 App 解压的，点「找解压出来的游戏」也能入库（套了好几层文件夹也认得出来，入库时自动整理）。ZArchiver 仍然可以作为手动方式。
- **模拟器**：内置的模拟器一键安装（不用联网）；没内置的给下载入口。

## 安装包

| 文件 | 说明 |
|---|---|
| `dist/Nagisaland_v0.6.3.apk` | 完整版，内置 `emulators/` 里的全部模拟器（F 盘上是分卷，双击 `合并完整版APK.bat` 合并） |
| `dist/Nagisaland_v0.6.3_lite.apk` | 精简版，不带模拟器 |

（旧版本的文件合并时会自动删掉。）

目前内置（都来自作者的官方 GitHub 发布页）：Kirikiroid2 1.3.9、Winlator 11.2、ONScripter-Jh 0.8.0、uEmuera 0.2.9c。

**想内置更多**（EasyRPG、PPSSPP、JoiPlay 及其插件、ZArchiver……）：把它们的 APK 放进 `emulators/` 文件夹，重新运行 `python build.py` 即可，
名字、包名、版本会自动读出来，App 会自动认出是哪个模拟器。
注意：闭源软件（JoiPlay、ZArchiver 等）打包进来只适合自己用，**不要把这种完整版发给别人**。

## 怎么用

1. 安装 APK。第一次打开要「所有文件访问权限」：点按钮 → 在设置里打开 → 返回。
2. 游戏放在 `内部存储/Nagisaland/Games/` 下，每个游戏一个文件夹（不用解包）；别的位置的文件夹用右上角 ＋ →「选择文件夹…」加进来；也可以走「小站 → 解压」流程自动入库。
3. 第一次在 App 里安装模拟器时，系统会让你允许 Nagisaland「安装未知应用」。

小技巧：游戏文件夹里的 `cover.jpg` 会被当作封面（从小站入库时会自动下载）。

## 游戏里

- 左侧按钮栏：`⋯` 收起 / 菜单 / 确定 / 快进（按住）/ 自动 / 隐藏对话框 / 方向键 / 修改器 / 退出到游戏库
- 修改器 →「找数值」：输入现在的数值搜索，游戏里让它变一下再筛，几次就能找到好感度之类存在哪个变量里
- 修改器 →「其它」：存档同步开关、把手机存档全部导出到文件夹、用电脑存档覆盖手机存档
- 右上角「返回」= 返回上一层（同电脑上的 Esc）；手机返回键也一样。游戏里的「退出游戏」会回到游戏库
- 修改器 →「按键」：方向键大小、左侧按钮大小、透明度、右上角返回键开关
- PC 版插件里的 `require('fs')` 等有兼容层（存到 App 里）；RPG Maker MV 自动改用 .ogg 音频（否则手机上没声音）
- 存档保存在 App 里，同时同步到游戏文件夹的 save/；游戏文件夹改名后，第一次打开会从 save/ 自动导回来

## 文件夹说明

| 路径 | 内容 |
|---|---|
| `dist/` | 打好的 APK |
| `app/` | 源码（apktool 工程）：`smali/` 安卓外壳，`assets/launcher/` 界面（index.html + core/library/site/extract/emulators.js），`assets/bridge-*.js` 注入游戏的脚本 |
| `emulators/` | 要内置的模拟器 APK |
| `build.py` | 构建：`python build.py 0.2.1`（传版本号自动加 versionCode；加 `--lite` 不带模拟器） |
| `nagisaland-mobile.keystore` | 签名密钥。**以后发更新必须用同一个，请备份，不要外传** |
| `tools/` | apktool、uber-apk-signer（构建需要 Java 11+ 和 Python 3） |

## 原理

- App 是全屏 WebView：界面是本地网页；网页游戏按游戏分配虚拟域名（`g<哈希>.nagisaland.game`），外壳把请求映射到游戏文件夹，并在 `index.html` 插入按键/修改器脚本。
- 小站请求走原生 HTTP（避开浏览器跨域限制），接口和电脑版相同（`/api/client/*`）；标题清洗、文件夹匹配的函数直接复制自电脑版 `galsite.js`。
- 安装内置模拟器、用 ZArchiver 打开压缩包，通过 App 自带的文件共享组件（`content://com.nagisaland.mobile.files/…`）临时授权给对方 App。
- 外壳用 smali 直接写（不依赖 Android SDK），代码在 `app/smali/com/nagisaland/mobile/`。

## 和模拟器的配合

| 模拟器 | 怎么打通 |
|---|---|
| PPSSPP | 直接带着 iso/cso 路径启动，点一下就进游戏 |
| uEmuera | 游戏移到 `内部存储/emuera/`（uEmuera 固定扫描这里） |
| ONScripter-Jh | 游戏移到 `内部存储/ons/`（它的默认目录） |
| EasyRPG | 游戏移到 `内部存储/easyrpg/games/`；第一次要在 EasyRPG 设置里把游戏文件夹选成「内部存储/easyrpg」 |
| Winlator | 游戏移到 `内部存储/Download/Winlator游戏/`（Winlator 默认把 Download 当 D 盘），在 Winlator 里打开 D:\Winlator游戏 运行 exe |
| JoiPlay / 吉里吉里（Kirikiroid2）/ mkxp / QSP | 这些 App 不扫描文件夹、也不接受别的 App 传游戏（检查过它们的安装包，只有普通启动入口），只能第一次在里面手动选一次：Nagisaland 会算好要选的文件（Game.exe / data.xp3 …）、复制好路径、给出每一步，JoiPlay 还会检查插件装没装；选过一次后就一直在它们的列表 / 最近记录里 |

移动后游戏库会自动把那个目录加进来，游玩时长、改的名字等都跟着走。

## 已知限制

- 内置 7-Zip 是自己用 zig 编译的 musl 静态版（arm64 / armv7，官方 26.03 源码，构建脚本在 `tools/7zip/`），打包成 `lib/*/lib7zz.so`。
- 有密码且文件名是 GBK 编码的 zip：7-Zip 在安卓上不转换 GBK 文件名，所以这种包由 App 自己读文件名、7-Zip 只解数据。分卷 zip（.zip.001）里的 GBK 文件名可能乱码。
- 解包需要和游戏一样大的空间（解到游戏文件夹里的 `nagisaland_www`）；解包后原来的 exe 可以删掉省空间，但电脑上还要玩的话别删。
- 非网页引擎只是帮你调起对应 App，能不能玩取决于那个 App。
- App 游戏和模拟器的游玩时长是按「从 Nagisaland 启动 → 切回 Nagisaland」计算的，中途不回来就一直算。
- 移动到模拟器目录只能在同一个存储里（内部存储 ↔ SD 卡之间移不了）。
